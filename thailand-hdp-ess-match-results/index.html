Two result systems → one local video history

Import HDP and ESS Thailand Match Results

A competitor who shoots events published through both HDP and ESS Thailand can import each accessible result and keep the already imported record associated with the corresponding match video in one local Shooting Cut archive.

Updated: 2026-07-29

The HDP and ESS Thailand communities materially overlap, so one competitor may need both result paths in the same video archive. Import still depends on each source exposing the selected result at the time of the network request.

Import before the source changes

ESS Thailand results may not remain browsable

The Thailand ESS portal normally exposes the current published match. When that published match changes, an older match or division-result address can stop showing the previous result.

Import the result while it is still accessible. In Shooting Cut, choose the available portal match, select the division, select the competitor, review the match and stage results, and save the intended record with the related video archive.

Important retention boundary: Shooting Cut can retain a result that was already imported into your archive. It cannot recover an older result after the ESS source has removed or stopped exposing it.

Finished matches and scoreboards

Select an HDP finished match and competitor result

For HDP, browse the available finished matches or open the intended scoreboard, then select the competitor result you want to import. Review the match and stage score information before associating it with a local video.

Start from the supported HDP import path inside Shooting Cut, then confirm the visible match title and competitor before saving the result.

Shared-shooter archive

Keep both result histories beside the matching videos

One shooter may have an HDP result for one event and an ESS Thailand result for another. Import each record from its own source, then explicitly associate it with the correct match or stage video in the local archive.

This creates one place to review the shooter’s imported score history and footage without claiming that every online record is matched automatically. Use the general result-import guide for the shared selection and verification steps.

Scores, not official shot-time anchors

HDP and ESS do not supply PractiScore-style per-shot timing

Both Thailand sources create score records that can be imported and associated with video. Neither source supplies the PractiScore-style official per-shot timer record used to anchor official times and splits to footage.

When a separate PractiScore result actually contains that official record, follow the PractiScore shot-time and score overlay guide. HDP and ESS imports remain score associations without that official per-shot anchor.

Quick answers

Frequently asked questions

Why should I import an ESS Thailand result while it is visible?

The Thailand portal normally exposes the current published match, and older match or result pages can become unavailable after that match changes.

Can Shooting Cut recover an ESS result after the source removes it?

No. Shooting Cut can retain a record that was already imported into your archive, but it cannot recover a result after the source no longer exposes it.

Can I keep HDP and ESS results with the same video archive?

Yes. One competitor can import supported results from both systems and associate those records with the corresponding local match videos.

Do HDP or ESS Thailand provide official per-shot timing?

No. Both sources support score import, but neither supplies the PractiScore-style official per-shot record used for timer-beep anchoring.
