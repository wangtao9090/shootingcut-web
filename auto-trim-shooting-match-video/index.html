Auto Trim One Shooting Match Video

Use Auto Trim when exactly one stage recording needs timer and shot analysis, start and end trimming, score or subtitle review, and export.

Updated: 2026-07-29

Auto Trim uses audio events to propose the active run and remove unused footage around it. The timer beep and detected gunshots are editing signals, not a substitute for reviewing the timeline and finished video.

Six-step workflow

Review the proposed trim before export

  1. Import exactly one stage recording. Choose the single video that contains the run you want to trim.
  2. Review the timer and shot analysis. Confirm that the timer beep, first shot, detected events, and last shot describe the intended run.
  3. Set trim padding. Adjust the footage kept before the timer and after the last shot so the exported clip has the context you want.
  4. Correct the event timeline. Move the timer marker, add or remove detected shots, correct the last shot, or adjust sensitivity and minimum split when needed.
  5. Review scores and subtitles. Check any imported score association and preview the selected timing or performance subtitle content.
  6. Preview and export. Watch the edited start, finish, and overlays, then export the reviewed stage clip.

Audio analysis does not locate target impacts. It helps identify timer-beep and gunshot events on the recording timeline so you can review the edit.

When the timeline needs attention

Common recording conditions can change detection

Automatic gain control (AGC), neighboring gunshots, echo or reverb, and a weak timer beep can make the proposed event timeline less clear. Inspect the waveform and detected events instead of assuming the first result is final.

Quick answers

Frequently asked questions

How many videos does Auto Trim use?

Auto Trim uses exactly one input video. Use Merge for sequential stage clips, Split Sync for exactly two simultaneous views, or Stage Mix for 2–3 simultaneous inputs.

Is Auto Trim free?

Yes. Auto Trim and score import are free. A free Auto Trim export includes the Shooting Cut watermark and logo intro card; Pro can remove the watermark and use a custom intro card.

Should I review the detected shots before export?

Yes. Timer and gunshot analysis is an editing aid. Review the timer marker, detected events, last shot, trim padding, subtitles, and final preview before export.

Does Auto Trim locate bullet impacts in the target?

No. Auto Trim analyzes timer-beep and gunshot audio events to support editing; it does not automatically locate bullet impacts on a target.
