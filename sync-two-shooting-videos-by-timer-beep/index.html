Sync Two Shooting Videos by Timer Beep

Use Split Sync for exactly two simultaneous views of the same run, aligned from timer-beep and audio evidence and then manually verified before export.

Updated: 2026-07-29

The two inputs must describe the same event from different viewpoints. Split Sync proposes a shared timeline, but the editor should still inspect the start beep and preview a visible or audible moment that appears in both recordings.

Exact input shape

Use two simultaneous recordings—not a sequence

Split Sync accepts exactly two videos. A typical pair might be a first-person view and a follow camera recorded during the same stage run.

If Stage 1 should play before Stage 2, use sequential Merge. If the same run has 2–3 role-assigned cameras and needs movement-aware switching, use Stage Mix.

Six-step workflow

Align, verify, and choose the composition

  1. Choose exactly two simultaneous recordings. Select two videos that show the same run from different viewpoints.
  2. Inspect each timer beep. Confirm that the start beep is present and identifiable in both audio tracks.
  3. Apply the proposed alignment. Let Split Sync use the timer-beep and surrounding audio evidence to place the two recordings on one synchronized timeline.
  4. Verify and correct sync. Preview a clear shared moment, compare the two views, and adjust the alignment if the proposed offset is not correct.
  5. Choose a layout. Select Full Screen, Dual View: Center HUD, Dual View: Top HUD, or Side by Side.
  6. Preview and export. Review the full synchronized run in the selected layout, then export the layout-controlled video.
Four product layouts

Choose how the two views share the frame

Current Split Sync layouts
Layout Composition purpose Output boundary
Full Screen Present one selected view as the full composition Layout-defined canvas with a 1080-pixel short edge
Dual View: Center HUD Combine both views with the HUD arranged at center
Dual View: Top HUD Combine both views with the HUD arranged at top
Side by Side Keep both views visible next to each other

The layout controls geometry. Split Sync uses its selected layout and a 1080-pixel short edge rather than arbitrary ratio-and-resolution combinations.

Editing responsibility

Audio alignment is evidence to review

A weak beep, automatic gain control, neighboring shots, or room echo can make one recording’s proposed sync point less clear. Compare both audio tracks and preview a shared visual event before treating the alignment as final. The detection troubleshooting guide provides a practical review order.

Split Sync is a Pro feature. Core audio analysis, editing, and export run on the Apple device; see the on-device data-flow guide for connected-feature exceptions.

Quick answers

Frequently asked questions

How many videos does Split Sync use?

Split Sync uses exactly two simultaneous recordings of the same run. It is not a two-or-more camera mode.

Which Split Sync layouts are available?

The four current layouts are Full Screen, Dual View: Center HUD, Dual View: Top HUD, and Side by Side.

Do I still need to verify timer-beep synchronization?

Yes. Timer-beep and audio evidence propose an alignment, but you should preview a clear shared moment and correct the offset when needed.

Can I choose any ratio and resolution for Split Sync?

No. The selected Split Sync layout controls the output geometry, and the layout-defined canvas uses a 1080-pixel short edge.
