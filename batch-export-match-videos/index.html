Prepared edits → separate export files

Batch Export Match Videos on Mac

Use Shooting Cut Pro on macOS to render several prepared match edits as separate output files instead of starting each export one by one. Every job still follows its editing mode, ratio, resolution, layout, and tracking limits.

Updated: 2026-07-30

Batch export reduces repeated setup when several finished edits or several permitted format combinations are ready to render. It does not replace review: timing, cuts, score fields, framing, and tracking should be complete before an edit is added to the output list.

Verified access

Batch export is available with Pro on macOS

The batch workflow is available with Shooting Cut Pro on macOS. It is not an iPhone or iPad batch-export workflow.

Core export work runs through the local Mac media workflow rather than a remote rendering service. See the on-device data-flow guide for the boundary between local editing and connected features.

Repeated-work shortcut

Queue prepared stage edits without rebuilding each export

Complete timing, cuts, imported results, framing, and any person tracking for each stage first. Then add several prepared match edits to the batch queue so the Mac can render them as separate output files instead of making you rebuild and start every export individually.

Batch export creates separate files and does not combine stages. Use Merge when the intended result is one sequential Full Match video.

Five-step workflow

Prepare every edit before adding export jobs

  1. Prepare every edit. Open each match edit, verify its timing, cuts, score fields, framing, and any person-tracking path.
  2. Open batch export on Mac. Use the macOS Pro batch-export workflow and select the prepared edits that should produce separate files.
  3. Choose permitted output combinations. Select only the ratios and resolutions available for each edit’s source, mode, and tracking path.
  4. Review the output list. Confirm that every listed job has the intended edit, format, resolution, and destination.
  5. Export and inspect the files. Start the local Mac exports, then inspect the resulting separate files before publishing or archiving them.

If a tracked format includes several clips, complete and review tracking for every included clip before creating the corresponding output job.

Per-job limits

Batch selection does not remove export ceilings

How output limits apply inside a batch
Output path Available choice Boundary to keep
General export Original, 4K, 1080p, or 720p when available The source and selected workflow filter the real choices; Shooting Cut does not upscale
Track-driven crop Supported portrait or square ratio 1080-pixel short edge, with 720p downscale available; not a tracked 4K output
Split Sync The selected Split Sync layout Layout-defined canvas rather than the normal Track ratio matrix
Multiple combinations More than one permitted output row Each row remains a separate export file with its own validated settings

Use the Reframe and Track guide to check supported ratios and the tracked-resolution ceiling before adding several format combinations.

Separate files or one long video

Batch export and Merge solve different problems

Batch export takes prepared edits or permitted output combinations and produces separate files. A set of stage projects can remain Stage 1, Stage 2, and Stage 3 as independent exports.

Merge takes up to 20 sequential clips and places them one after another in one long Full Match video. Use the full-match Merge guide when the goal is a single video containing every stage.

A useful decision: choose batch export when the outputs should stay separate; choose Merge when the stages should become one continuous timeline.

Quick answers

Frequently asked questions

Where is Shooting Cut batch export available?

Batch export is available with Shooting Cut Pro on macOS.

Does batch export combine all selected stages into one video?

No. Batch export produces separate output files. Merge combines up to 20 sequential stage clips into one long match video.

Can every batch job use any ratio and resolution?

No. Every job remains subject to its source, editing mode, layout, ratio, resolution, and tracking ceiling.

Can a tracked crop be a 4K batch output?

No. Track-driven crops use a 1080-pixel short edge and may be downscaled to 720p; they are not tracked 4K outputs.
